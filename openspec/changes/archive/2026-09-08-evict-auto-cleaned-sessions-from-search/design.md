# Design
Expose successful cleanup deletion identities to the caller without a global-home dependency in the storage adapter. Prefer the smallest callback/result boundary that preserves counts and does not require another persistent store. Wire the production cleanup wrapper to existing root-scoped search enqueue. No notification for fresh, skipped, writer-held or failed candidates. Verify removal through the existing missing-summary path, including absent-index behavior. Keep asynchronous eventual eviction semantics and indexing-disabled deletion handling. Tests use explicit temporary roots; no process-global cleanup on user history.
