# Selected design
Use a content-derived batch directory beneath assets, not an additional catalog. Fingerprint ordered decoded normalized image bytes and extension, with explicit lengths/domain separator. Group identity is independent of transient Turn/prompt IDs: repeated ordered normalized batches across retry, resumed FIFO, merged-input preparation or synthetic origins reuse the same batch. A different ordered batch has a different namespace; cross-batch per-image dedup is not claimed.

Existing ContainedDirectory create_child, write_atomic, read_bounded, rename_child_no_replace and remove_tree_child provide the necessary ownership. Verify every expected file in an existing batch against decoded bytes, rejecting corruption or symlinks. Otherwise create a UUID staging directory, write all files, close its handle, publish via no-replace rename, then sync the parent. Only a successful directory publication becomes reusable. A concurrent loser verifies the winning batch and cleans only its own staging directory. Post-publication parent-sync failure warns without inviting deletion/retry of a committed entity.

This supersedes per-file rollback internally: unpublished temporary batches are exclusively owned and removable, published/reused batches are never rollback candidates. Input commit errors (including AcknowledgementLost) leave published batches alone, as current admission already does. Successful paths remain valid for history/fork references; no old UUID file migration or deletion. Crash-left staging directories and unreferenced distinct published batches are not garbage collected here. Creation/sync/cleanup failures can leave staging; this is not an overall disk quota.

Validate stable retry without writer calls, corruption rejection, failed new batch preserving an earlier published batch, concurrent publication collision, and existing save tests. A retry after uncertain commit is modeled by reusing the same batch without any deletion step; no new full Timeline ACK-loss harness is required because admission behavior is unchanged.
