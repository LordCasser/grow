## Decision

复用 canonical Step diff、现有通知的有界目标与验收快照、直接委派绑定以及 Received/Consumed/Handled。状态字段仅在改变任务可执行意图时触发。回合执行把首次查询的父快照保留在局部变量，后续请求和重建复用该快照。子 Agent 本地计划继续从当前 Timeline 投影，父计划变化从已交付通知获取。子 Agent 用结构化操作一次性确认所处理的来源，业务答复留给实际影响和交付。

已经提交的通知可能使用旧版指导措辞。重试对同一已收到的计划责任验证旧版完整 payload 哈希，沿用原通知身份。新接纳使用新版措辞。停止指令与持久化边界保持。
