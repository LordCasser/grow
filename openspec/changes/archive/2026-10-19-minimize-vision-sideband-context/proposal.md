# Minimize visual sideband context

The visual auxiliary currently receives user- or tool-authored source text together with image attachments, even though its result becomes a durable, reusable image description. This couples the description to incidental conversation context and sends more information than the image task requires. Recovery progress and outcomes also need one stable, English operation row across vision, OCR, cancellation, and replay.

Keep the visual auxiliary request to the attached images and one fixed English prompt. Keep source Surface references as local Sideband provenance and use the fixed prompt for cache and durable-result matching. Render visual recovery as one stable ordinary operation row with English status text while preserving OCR/image recognition output in its original language. The canonical unsupported-image replacement remains unchanged.
