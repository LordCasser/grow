## Design

Keep the validated root lifecycle facts and exact index access with the existing history cut. Bind ownership to the page selected by Latest, Before, After or Around. Match session ID and subagent ID before walking each immediate parent edge by the canonical child key. Canonical facts use the lifecycle-root Timeline while the security parent defines the tree and the valid notification route.

Pager adopts page metadata after its existing binding, generation and cut checks. Reuse the existing state-only Spawned and Finished reducers, preserve already observed terminal state and leave historical body rows at their original positions. Before reading a child transcript, validate its Summary, Seed and any referenced Result using the lifecycle-root identity. A parent terminal still describes cancellation or failure when there is no child result, and a missing child offers no detail action.
