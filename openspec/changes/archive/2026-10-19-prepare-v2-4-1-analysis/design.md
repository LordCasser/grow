# Design

先审查已完成任务、场景及证据，使用 OpenSpec CLI 归档并合入主规范。开发者说明引用主规范，历史验证引用归档位置，保留此前验证的时间和平台限制。

所有整合在独立 worktree 进行，以 main 的已提交 HEAD 为基线，检查 Plan 状态、TODO 恢复与本轮控制回执、采样失败、操作行的交互。main 的 MCP 工作不进入本轮提交；合入前保存并核验未提交改动，必要时使用三方合并保留其原有增量。

发布分析区分已有本地证据、组合后的验证、尚未执行的原生平台/真实发布。静态检查不可冒充 tag 预检或原生 Windows 运行。只记录本次范围外的债务，不顺带扩展实现。

完整组合回归在 Agent 包捕获三个 prompt-size 断言失败：通用子 Agent 8672 bytes、只读 8197 bytes，而旧上限为 8192/7680。新增写入位置文字有 550 bytes 左右，之前该纯文本 change 没重跑 Agent 包。精简这段重复授权表述但保留全部约束，将各上限增加 512 bytes，明确为这段共享安全指引预留，不改原 Audience、角色或装配逻辑。体积测试继续约束完整渲染结果与只读相对尺寸；不以删除测试或宽泛放松预算处理失败。
