## Scope limits

Storage repair only proceeds after the old writer's active filesystem operation drains. A replacement writer must sync the recovery prefix before reopening admission; a failed sync barrier leaves the shared domain closed. `storage_admission` 6 and JSONL 162 cover these gate, lease, and sync boundaries, while the child-process writer-replacement test covers replay of an already durable input identity. Cleanup rechecks references under the writer lease and preserves candidates when scanning is incomplete; standalone GC preserves session-owned worktrees without session authority. Parent/child source-chain deletion remains a conservative-preservation backlog item. Physical ENOSPC is not simulated. Tools task 187 covers the 8 MiB cap for uncommitted output; bytes held only in memory may be lost if the process exits before durable commit.
