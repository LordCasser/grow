The PromptWidget constructor builds only the primary-eligible visible built-ins. The normal `/agent` picker opens immediately with those choices and schedules a filesystem discovery effect. This effect shares the Pager agent-discovery semaphore and five-second deadline with `/config-agents`; a timed-out `spawn_blocking` scan retains the permit until its thread exits. On completion, the owning AgentView checks its picker request token and session binding. It stores the new catalog for later prompt suggestions and replaces the still-open picker's items in place, preserving the user's filter and selected Agent when possible. An error leaves the valid built-ins and reports that additional Agent definitions could not load.

Workflow child pickers continue to use immutable Run snapshot names and do not perform a live scan. Direct `/agent <name>` dispatch remains Shell-authoritative and does not require local catalog membership.
