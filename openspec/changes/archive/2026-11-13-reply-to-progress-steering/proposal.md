# Reply to progress steering without ending work

## Why

A progress question admitted into running work can receive a visible reply that the provider marks as an end turn. Grow then treats the reply as an attempt to finish the original work, so unchanged delivery obligations can fail the turn even when the reply explicitly says the work is still in progress.

## What Changes

- Give the model a provider-neutral way to send a visible interim reply to an admitted steer and continue the same turn.
- Preserve the existing planning completion gate for actual terminal answers.
