# Plan Acceptance Matrix

以下定义验收要求。实际执行状态见 [verification.md](verification.md)；通过必须记录具体测试/夹具、可观察事实和未覆盖限制。

复用 pager-pty-harness 的 plan_approval_resume 和历史 Plan PTY；P-07～P-15 同时需要 Shell/Timeline 持久化、竞争和故障注入，不以 UI 测试代替后端证据。

P-17～P-24 为架构复审补充；P2 的身份、持久化、恢复和回收边界必须一起验证，不能随 UI 开放后留待后续补齐。

| 编号 | 操作/故障注入 | 可观察的通过条件 |
| --- | --- | --- |
| P-01 | v1 提交后收起，再用已有入口打开 | 正文和 revision/hash 相同；未产生批准、拒绝或执行 |
| P-02 | 没有 legacy `plan.md`，只有合法 immutable artifact | 审批外预览仍成功，读取后端引用，非残留界面缓存 |
| P-03 | 保留稍后审阅，结束原 turn，再打开 | 不依赖原 oneshot；可形成新的真实审批关系；无后台自动执行 |
| P-04 | 保留后退出/重启，查看但不批准 | 候选仍可发现；仅查询不产生实施 turn |
| P-05 | 无活跃 turn 时批准恢复的计划 | 沿现有 resume/PlanHandoff 启动一次实施；验证的是回归和新入口接通 |
| P-06 | live turn 审批携带评论 | feedback 只消费一次，无额外普通 prompt/Interject 副本 |
| P-07 | 看着 v1 时另一路提交 v2，再点批准 | 旧决定被拒绝；显示新版本需重审；不执行 v2 或旧版本 |
| P-08 | 未批准 v1 要求修改；另测已执行计划 amend | 前者回 Drafting 后 submit v2；后者保持 Amending 直到重审；编辑限制正确 |
| P-09 | 批准已提交但 ACK 丢失，客户端重试 | 原决定身份被复用；查询/核对得出原结果；只有一次执行交接 |
| P-10 | 两个客户端同时批准或批准/放弃竞争 | 一份决定胜出，另一份明确过期/冲突；无双执行 |
| P-11 | artifact 缺失、hash 不匹配、过大或非法 UTF-8 | 明确不可用，不从历史文本猜正文，不启动实施 |
| P-12 | 队首输入被编辑 hold、另有前台任务、Goal/Workflow owner 存在 | 后端按既有可用性和仲裁接纳或等待；计划不旁路起第二个 owner |
| P-13 | 执行接纳失败或 storage gate 关闭 | 计划和评论保持可审阅；状态为受阻/未确认，不乐观清除 |
| P-14 | 退出 Plan 后重新创建相同正文；旧窗口迟到批准 | 跨周期身份不混淆，不错误去重掉新决定，也不复用旧批准 |
| P-15 | 延后到 artifact 回收窗口之后 | 有保留引用的正文仍可读取；取消保留后才按既有资格规则回收 |
| P-16 | 保留/审阅/执行的全部键盘流程 | 顶部 task 布局不变，草稿不丢；未出现统一 Dock 或其他排除功能 |
| P-17 | live submit/amend 与 idle waiter 各执行 defer；在提交前、ACK 丢失、提交后工具终态前注入失败/崩溃 | 原工具至多结算一次；无 ResampleStep/旧计划执行/自动重弹；未确认保留内容，恢复只补合法收尾 |
| P-18 | 保留后切 Normal/Goal/Workflow，再写入并冷恢复 Control | 独立候选有效，Plan runtime 无跨模式残留；非法字段仍拒绝；普通查看不建审批 waiter |
| P-19 | 同决定身份重试相同内容，再改变 action/feedback/候选 | 前者返回原状态，后者冲突；无新 handoff/反馈副本 |
| P-20 | 决定排队未写入时查询；旧 writer 尚有在途写入时查询 | 未找到不等于未接纳，不准以新身份重发；负面确认有合法 owner/退出证据 |
| P-21 | fork/导入保留或已批准计划；rewind 后旧窗口/已消费 handoff 到达 | 不继承或复活执行资格；跨 session 新提交重审；来源不明不执行 |
| P-22 | 慢读取期间切 session/关闭重开/v1 换 v2；保留 v1 行评论 | 输入不阻塞；迟到结果不覆盖新展示，评论仍属 v1，不自动套到 v2 |
| P-23 | 未确认批准与候选替换竞争；执行/放弃后重新点旧批准；分别批准说明与要求修改 | 未决身份不丢；旧提交不再可批准；要求修改必须新正文重审，说明不覆盖冻结正文 |
| P-24 | 整 session stale cleanup；放弃但仍有历史/未确认引用；扫描后新引用 | 目录和 artifact 都受保护；删除边界重核对，引用不可读时保留；没有独立计划 GC |
