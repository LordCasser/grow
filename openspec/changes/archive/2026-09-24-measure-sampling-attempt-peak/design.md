The benchmark uses `MockInferenceServer` and `run_headless_in_sandbox` so the actual built `grow` binary exercises its Chat Completions SSE path with isolated HOME and workspace state. `/usr/bin/time -l` wraps each invocation and its maximum-resident-set-size line is parsed from stderr. The large response is divided into roughly 16 KiB SSE text deltas and totals about 12 MiB; the test prints both measurements without imposing a platform-dependent memory threshold.

The automatic title request uses a separate mock model endpoint with a short fixed response, so only one large foreground Chat Completions request contributes to the measured response workload. The test is ignored and macOS-only because it depends on a pre-built binary and Darwin's `/usr/bin/time -l` output. No runtime queue or sampling code is changed.
