## Design
抽出私有单次元数据采样函数，版本读取和类型分类通过闭包传入，生产闭包仍使用同一 pb 对象并在既有 try_lock 内运行。顺序为版本、分类、版本。只有版本相等且分类可用才返回有效版本；其他情况返回 (None,false)。无原地重试，避免连续复制造成 UI 忙循环。

调用方已有未知语义：提示不提交去重并在后续节流机会重试，附件门禁不据未知排除图片。保证仅限探测期间观察到的版本变化，不承诺返回后剪贴板永远不变，也不改变后台读取的后续 staleness 检查。

## Validation
注入版本/分类闭包验证稳定正负结果、前后版本变化、分类不可用及执行顺序；不访问系统剪贴板。保留忙锁测试并运行 attachment gate 相关测试。
