The modal owns a monotonically allocated instance token and a loading flag. The root reducer installs the empty modal immediately and emits a fetch effect. The effect captures owned cwd, loads toggles/default and discovers definitions inside one `spawn_blocking` worker guarded by a single permit and a five-second request deadline. Timeout ends the wait, not the filesystem call; the worker retains its permit until it exits. A result applies only if the same agent and modal token are still current. The active agent name returned by the independent session-info request is preserved.

When the external editor exits, the open modal begins a new tokened reload and queues the same effect. A successful toggle updates its in-memory `enabled` flag because no source changed. Closing or reopening the modal makes old completions harmless. No persistent format or Shell catalog authority changes.
