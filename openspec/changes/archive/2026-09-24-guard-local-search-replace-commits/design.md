# Design

Keep the existing read and edit calculation unchanged. Extend `AsyncFileSystem` with one existing-file conditional write that receives the exact prior bytes and proposed bytes. The default adapter response is Unsupported. The mock filesystem checks and updates under one write lock. LocalFs performs the operation on a blocking worker: open the target, acquire an exclusive advisory file lock with a five-second acquisition deadline, compare bytes, verify that the path still names the opened file, write through that descriptor, and release the lock. A changed file or replaced path returns a conflict; an unavailable lock returns a timeout without writing. The lock is on the target file rather than a process-local mutex or a persistent sidecar, so separate Grow processes and aliases to the same inode participate. The opened descriptor is the write target; a pathname replacement cannot redirect the write to a different file after open.

This is a cooperative edit commit, not a general filesystem CAS. An arbitrary external process may ignore the advisory lock and change the same inode during the compare/write window. Do not claim otherwise. The edit tool reports an unsupported adapter or changed source as an actionable edit failure and does not publish a file-written notification. The existing no-replace path remains the only path for missing targets.

This limit follows from the available generic local-file operations: Linux `renameat2` exposes no-replace and exchange, Apple documents exclusive rename, and Windows `ReplaceFileW` replaces a destination, but none of those APIs takes expected target bytes as an atomic predicate. That conclusion is an inference from their documented parameters, not a claim about every specialized filesystem transaction API. References: [Linux rename(2)](https://man7.org/linux/man-pages/man2/rename.2.html), [Apple exclusive rename](https://developer.apple.com/documentation/foundation/urlresourcevalues/volumesupportsexclusiverenaming), [Windows ReplaceFileW](https://learn.microsoft.com/en-us/windows/win32/api/winbase/nf-winbase-replacefilew).
