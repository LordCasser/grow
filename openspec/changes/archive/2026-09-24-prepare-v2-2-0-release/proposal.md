## Why

The repository still reports v2.1.11, so a v2.2.0 release would otherwise build binaries with stale version metadata and have no matching release notes.

## What Changes

- Set the workspace and local lockfile package versions to 2.2.0.
- Add v2.2.0 release notes and link them from the shell changelog index.
- This is release metadata and documentation only; runtime behavior and archived behavior contracts do not change. The notes summarize behavior already implemented and documented by the changes included in this release.
