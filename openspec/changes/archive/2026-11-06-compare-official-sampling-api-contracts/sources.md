## DeepSeek 官方兼容说明

除上面的thinking/tools两个关键切换来源外，还亲取了[首次调用](https://api-docs.deepseek.com/)、[Chat create](https://api-docs.deepseek.com/api/create-chat-completion/)和[错误码](https://api-docs.deepseek.com/quick_start/error_codes/)。首次调用直接推荐OpenAI/Anthropic兼容SDK；未把第三方封装称为官方DeepSeek SDK。Chat create明确最后usage随单choice/finish帧发送而非OpenAI的choices=[]额外尾帧；HTTP错误表不能给任意SSEcode自动生成重试许可。

证据目录 `/tmp/grow-official-chat-GcDkz73j/` 中*.html是原始HTTP响应，*.txt为article/main提取，仅用于定位，不是新增契约；http_fetch_manifest.json和cross_model_artifact_manifest.json记录来源与hash。旧guides/reasoning_model不再提供该文档：MCP为PageNotFound，直接GET为200且与首页body相同，按语义失效记录，不笼统称HTTP404。

重复JSON key的讨论仅引用 [RFC8259 §4](https://www.rfc-editor.org/rfc/rfc8259.html#section-4)：名字SHOULD唯一，接收者可取末值或报错；没有将它写成所有官方SDK统一拒收的MUST规则。
