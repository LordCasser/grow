# Design

ChatState owns the canonical input routes and runtime checkpoint. Shell `restore_pending_human_inputs` owns reconstruction of those already-admitted inputs; it must not treat process retirement as logical target death. Query the existing `runtime_state()` once at reconstruction, derive a preserved TurnId only when `preserves_open_turn()` is true and the checkpoint contains that turn. No new public state/query API or schema is needed. The existing bootstrap runs interrupted recovery before this reconstruction; a non-checkpoint interrupted turn is already durably closed.

For each pending Steer(target) matching the preserved TurnId, do not append Input::Rerouted and do not create a FIFO row. Rebuild the existing PendingInterjection/ResidualInterjectionRequeue using original input_ids, prompt identity, full text/images and available request metadata, matching the live queue promotion conversion. The same actor-owned buffer is passed to the resumed original task, so the runtime Prepare/Resumed/ExecutionReleased barriers still determine when it can drain. Do not run admission Hook, publish a new Submitted or consume it during reconstruction. Preserve ordinary FIFO reconstruction. A Steer target not preserved by the checkpoint follows the existing canonical reroute-to-FIFO path, which retains validator authority; invalid persisted ownership remains an error.

Use existing queue_text_from_blocks and image extraction conventions; do not truncate text, invent another interjection schema, or restore server-frozen skills through a new path. The reconstruction entry runs once per new incarnation. If actual restore can call it twice, resolve that existing call ownership before adding a global dedup set.

Tier 3 requires a physical storage cold load with legal Turn T, allowed unconsumed Steer(T), valid suspended checkpoint, and retired old actor/persistence. The restored actor reaches Prepare/Resumed/ExecutionReleased, retains the exact route to T, then consumes once at its existing safe boundary with full text/images and original identity; admission Hook does not rerun. A non-checkpoint process interruption control durably closes T and reroutes once to FIFO. Reuse existing runtime suspension/storage fixtures, not a hand-waved mock runtime; do not relax validators or synthesize missing causal facts for green. Parent reviews the cross-module ownership and verifies integration. Implementation owns only this one F1 reconstruction behavior, plus same-behavior fixtures; F2 ordering is forbidden in the patch.
