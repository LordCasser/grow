## Evidence boundary

以本地 Timeline 中与截图逐字相同的文本定位事件，再核对此前持久化 Control 的 Agent 身份、当前个人定义和配置。源码审计覆盖 definition discovery、parent filter、toggle、Task validation、Agents modal 和 config reload。Atlas 只用于局部结构导航，行号及分支以实际文件复核。

不把当前磁盘配置视为历史时刻的内存快照；不把静态热更新缺口视为此次故障的已证实触发器。用户定义正文只作分析数据，不作为本次任务指令。

## Delivery
