## Design

Shell keeps the existing durable Input route, consumed event and display echo. Move the live interjection broadcast from admission to successful consumption and carry the message identity already used for replay. Retain enqueue diagnostics and keep the existing tool batch boundary, attachment handling and cancellation routing. Pager can report that a direct steer was queued as transient feedback. Its transcript uses the Shell broadcast and the existing message identity for reconciliation with replay.

Pager permits the existing pristine rewind only when the stashed submission has the same prompt identity as the foreground. Removing the last visible queue row for steering does not transfer its stash to the current turn.

The change addresses the documented display duplication. It uses the same input identities and does not deduplicate by text.
