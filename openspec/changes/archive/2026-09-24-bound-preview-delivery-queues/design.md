# Design

Reuse the session preview credit budget's 16 KiB / 4096-credit size model for a separate gateway budget. Count the serialized notification with a streaming writer (no second payload buffer), reject an item larger than the budget, then atomically try-reserve its credits. Send through the gateway completion API and hold the permit in a bounded completion task until acknowledgement or receiver loss. Do not block the session event loop waiting for a client. A failed reservation sends a small, ordered `SamplingPreviewFailure` message to the persistence actor; its existing sticky attempt error makes the pre-admission barrier fail closed. Live preview is best-effort on client disconnect, but resource overflow is not silently accepted.

For untagged ACP notifications emitted while an attempt is active, send an acknowledged persistence command and await its exact append. The persistence actor records a sticky failure on any append error and replies after the write; the actor can then continue client delivery. This keeps one independent update in flight through this producer and preserves its position relative to the candidate marker and admission barrier. Outside an active attempt the ordinary update path is unchanged. Control and terminal messages remain small and outside the payload budget.
