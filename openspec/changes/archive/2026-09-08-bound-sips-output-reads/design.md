## Design
A private output loader opens the file, checks same-handle type/length and delegates to a bounded reader. Unix O_NONBLOCK|O_NOFOLLOW rejects substituted special sources. Use100MB as an independent converted-output ceiling, allowing expansion relative to50MB source admission without claiming all valid source encodings must fit. Empty, oversized or unreadable output returnsNone and follows existing Rust fallback.
## Limits
This bounds Rust consumption of the completed sips output, not disk bytes produced before checking, total RSS or Rust fallback output. Metadata is an early rejection only; take(limit+1) supplies the actual consumption bound. No immutable filesystem snapshot or I/O deadline is promised.
