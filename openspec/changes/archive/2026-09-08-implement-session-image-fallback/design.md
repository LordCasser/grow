## Confirmed architectural gap
`SessionActor::project_conversation_images_for_text_model_once` currently installs irreversible ImageShadows: after one route rejects an image, later routes also consume descriptions. This contradicts the newly requested first-image-attempt behavior for each provider/model tuple. Reuse durable original image evidence and validated description provenance, but make selection route-dependent rather than globally irreversible. Existing transport keys hash model/backend/endpoint, not canonical provider/model identity; inspect canonical route ownership before changing markers. No local OCR implementation was found in the image recovery chain. Keep the existing deadline, cancellation, concurrency and durable-write failure boundaries.

## Implementation decision
Extend existing ContentPart::Image with an optional description, retaining URL and description together. ImageProjection remains the acknowledged event and keeps its replacement Surface identities, but attaches descriptions rather than deleting original image parts. Existing tool-reference/native-carrier sanitization remains; provider request assembly selects descriptions only for a rejected canonical provider/model pair. Unknown pairs retain original image parts. Description selection occurs before request byte-budget eviction and native continuation reconciliation; foreground/background compaction also selects descriptions for its prepared target. Never resubmit a request with unresolved image descriptions.

Keep ModelImageInputKey as transport provenance for Workflow and image events. Change only the session negative capability state to canonical catalog model IDs (provider/model); capture that ID alongside request transport identity before provider work. Effort and endpoint decoration do not create a new capability observation. Auxiliary routes use their configured canonical model ID.

Reuse valid attached descriptions without another Sideband. Missing descriptions first use the existing bounded, durably validated visual Sideband. If unavailable or failed, use local tesseract via stdin/stdout with a bounded subprocess lifetime/output and no shell; retain OCR provenance in ImageShadowSource::LocalOcr. Persist all descriptions as one acknowledged ImageProjection; any unresolved group prevents lossy publication/retry. Original image data is never deleted by fallback. Local OCR accepts bounded inline image data; unsupported remote sources fail explicitly rather than fetching arbitrary URLs. Cancellation kills the child. Show the requested Chinese processing messages through an explicit image-processing notification in the TUI, then display the completed projection notice. No persistent UI owner or retry loop is added.

The inactive normalization cache deletion was completed separately at ee226a79, with 40 passing regressions.

## User clarification: recoverable image failure
If both descriptions fail, finish only the current request with a clear unsupported-multimodal message and manual model-switch/rewind guidance. Do not auto-rewind, remove images, mark a session fatal, or install an incomplete ImageProjection. Normal image errors must leave Timeline replay and manual rewind usable. Genuine persistence corruption retains its independent strict durability boundary.
