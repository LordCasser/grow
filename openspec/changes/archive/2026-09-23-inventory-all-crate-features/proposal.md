## Why

原目标是逐个遍历全部 crate，并把所有发现的功能写入 OpenSpec。现有资料确实留下 61 个 Cargo package 与 2,163 个源码文件的快照证据，但 44 份候选 delta 含 4,290 条要求，尚有 136 处功能映射错误或缺失、12 条失效来源路径和 7 条空来源。格式校验不能证明这些条目是正确的行为契约。继续按文件数量机械补齐并一次性归档，会把未核对的实现细节变成主规范。

## What Changes

- 将本 change 收口为带来源快照的历史审计资料，保留逐包 review、feature map 与候选要求供后续定向调查。
- 将未核对的 delta 移到 `reviews/draft-deltas/`，标记为非规范草稿；本次不改主规范或 Rust 行为。
- 取消原先“全仓所有功能一次性入规范”的无界验收目标。后续只在具体行为 change 中核对当前源码、调用方和测试，并增补必要的能力规范。

## Impact

仅变更本 change 的文档归属和状态。原逐包资料对应 `45e3a161` 源码快照，不代表当前工作树、动态行为或全仓功能覆盖已经验证。
