# 资源与路径诊断清理

## Why

完整 Clippy 仍有 58 项资源/路径诊断：47 禁用方法、7 await 持锁、2 打开选项、1 无 Drop 值释放、1 可选 Tokio 路径不可达。需要逐处核对所有权和 Windows 路径规范化，而不是统一关闭诊断。

## What Changes

复用现有 dunce/异步文件系统助手；在 await 前释放不再需要的锁，并保留通知归属与入队的原子边界；明确日志不截断；删除冗余 closure drop。自有监督/kill/wait 的辅助进程和并发测试保留精确的带理由 expect；可选 Tokio 配置仅允许方法不可达，不取消实际调用的禁用规则。不改产品/持久化协议、恢复/就绪边界或进程生命周期，skip_specs。
