## Scope exclusions

Do not multiply every route family by every target phase, backend, failure, behavior and UI surface. Reuse source identity, Sideband projection, parser/ledger and generic notification tests. Do not assert that a provider read committed input before a request was sent, that compaction preserves full uncompressed text in the live window, or that arbitrary concurrent schedules make infinite progress. Deletion assertions must follow current preflight/lifecycle source rather than assume deletion is rejected or delayed for every race.
