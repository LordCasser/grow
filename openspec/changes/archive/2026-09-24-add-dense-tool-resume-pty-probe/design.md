## Design

Extend the existing resume latency fixture and measurement helper with an opt-in dense-tool mode. Preserve both current ignored test cases unchanged. The new 512-turn case keeps the 40 ms frame-writer delay and begins typing as soon as the visible `Loading session` prompt appears, before waiting for replay output. This puts the draft and all 20 key echoes inside the load/replay window; the test checks after each echo whether the final history marker has appeared, then verifies draft survival after load. It also records when the first streamed replay marker appears and prints phase timings before asserting the marker stayed absent through all key samples. One ACP `tool_call` and one matching `tool_call_update` remain interleaved after every historical turn's eight streamed chunks.
