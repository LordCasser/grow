# 对抗性审查

| 反例 | 本次处理或既有边界 |
| --- | --- |
| child 仍运行，但 parent 尚有独立工作 | 保留继续独立工作的优先级，不强迫 spawn 后立即等待。 |
| parent 工作耗尽，创建 sleep/轮询/另一个 child 占位 | primary 与 spawn 指向原 ID 的任务输出阻塞等待，回执给出可调用示例。 |
| 工具和参数被重命名 | 工具名与参数映射来自现有 TemplateRenderer，JSON 用 serde_json 构造；不能硬编码另一工具集名称。 |
| 等待上限低于固定示例值或等于零 | 示例使用当前上限；零上限不生成假阻塞示例，不改变配置语义。 |
| A 能解锁后续工作，B 无关且仍运行 | 保持 wait-all，如需多任务只选择下一步全都需要的依赖，不声称 wait-any。 |
| 超时返回 running/initializing 或状态观察未知 | 仅结束本次等待，不宣称 child 成功、失败或原工作完成；不制造睡眠任务。 |
| child 失败、取消或任务 ID 不可观察 | 依据真实结果决定后续处理，不把查询失败当成功，不重派相同任务掩盖问题。 |
| 用户 steer/stop，child 随后完成 | 复用既有可中断等待、通知与取消 owner；结束 waiter 不等于停止 child，用户 stop 不被迟到事件绕过。 |
| 已结束后才调用等待、完成与 waiter 注册竞争 | 沿现有 coordinator 已完成快照与注册边界，不新增第二份 waiter 或状态账本。 |
| 树恢复重建后台回执 | 同一 formatter 使用恢复后当前 renderer 的参数映射；不另派 task 或改写子任务身份。 |
| 工具集不支持 subagent | 仅 task 启动/恢复产生子任务回执；primary 用“已有 child”条件，命令专用输出工具不增加子任务文案。 |
| 合法定时测试也使用 sleep | 禁止范围仅为等委派结果的占位，不增加命令内容检测或拦截。 |
| 模型仍自行调用 sleep | 本次是模型指引与入口改进，不是硬执行策略；无实际模型评测时不宣称彻底消除此行为。 |

现有 runtime 在本次范围内保持；验证记录应区分已运行测试、源码审查和未做的真实模型/交互评测。
