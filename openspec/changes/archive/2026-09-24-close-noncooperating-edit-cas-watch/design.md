# Design

Do not add a sidecar lock database or another edit protocol merely to name an impossible guarantee over independent tools. The actual contract is conditional bytes plus a target-file advisory lock for cooperating Grow writers, with no success notification when the condition or target identity fails. An external writer that finishes before comparison is detected by the byte check. A simultaneous external writer that ignores the lock is outside that guarantee. Linux rename no-replace/exchange, Apple exclusive rename and Windows ReplaceFile are namespace operations without an expected-content predicate; this is an inference from their documented parameters, not a statement about every specialized filesystem. The limitation is already explicit in the archived implementation change and developer guide.
