## Design
Shell knows the committed journal boundary after child creation and before accepting its first input. Advertise that boundary only for a live child with inherited presentation. Read the identity-checked canonical child journal only through that boundary in a blocking worker. Project display rows and measure the width of their source lines there. First layout can reuse those measurements at any terminal width. Merge the rows before live rows using the existing Pager scrollback prefix operation. Bind completion to the initiating child view. Keep existing durable source validation for parent-child lineage and measure its cost separately.

## Verification
Exercise interleaved live and inherited display, stale or failed reads, retries and terminal state. Compare identical production source lookups for one, two and four children of a single parent. Report logical reads separately from physical storage traffic.
