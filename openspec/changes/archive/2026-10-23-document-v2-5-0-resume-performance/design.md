# Design

只用已归档的正式 release 配对中位数，不采用 debug 6.69 秒，不把不同阶段或工具链串成一次版本对照。C3 后端 RPC 和 P1 / 最后扫描优化的 PTY 末条可见分行列出，各自为三对 AB/BA、温热文件缓存；链接固定发布提交内的归档证据。保留首屏不一定提速、短会话及图片/输出负载不保证同收益的边界。

已发布 tag 的源码与全部资产保持不变。GitHub Release 正文允许按用户要求更新，读取回核对全文，同时比较 release id、tag object/commit、资产 id/size/digest、draft/prerelease/latest 未变化。原发布记录中 notes 与 tag 一致的结论明确限定为发布时，避免将后续编辑误判为当时验证失败。
