## Why

共享 system prompt 的 action_safety 已说明授权、可逆性和保留用户文件，但没有默认写入位置。Agent 可能为方便把临时脚本、输出或配置放到 home、其他仓库或任意绝对路径。用户要求默认使用打开的项目目录与 /tmp，仅在明确要求或任务明确需要时写入其他位置。

## What Changes

在 Mandatory Core 增加一段英文指导：文件创建和写入默认留在当前项目/活动 worktree，临时产物使用 /tmp 或平台系统临时目录；外部写入必须有明确用户目标或该位置的任务必要性，并限制在必要文件。路径可写、给出绝对路径或方便本身不构成理由。

# Impact

只修改共享提示词及开发者说明。主 Agent、子 Agent、extend/full 均复用该核心。不修改权限判定、文件工具或持久化历史，不新增目录配置或审批流程。
