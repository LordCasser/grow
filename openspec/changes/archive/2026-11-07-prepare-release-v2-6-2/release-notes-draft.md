## 问答与控制反馈

- 新增建议式（Advisory）问答模式：Settings 允许 Agent 按次选择问答方式；关闭建议式后，实时会话与恢复会话都强制阻塞式确认。建议式问题可在任务继续后补答，补答按普通输入接纳。
- 改进子 Agent 模型调整的状态反馈：已排队（Queued）、已生效、失败在同一行如实更新，已排队不等于已生效；生效后只提示一次，并按实际目标模型与推理力度请求。

## 输入队列与恢复

- 编辑排队输入后，恢复会话保留原队列位置，并按编辑内容对应的不可变输入身份消费；转向消息恢复到原回合，重试沿用稳定身份。

## 流式采样错误识别

- 修复流式输出中零星 error 信封被误分类的问题：HTTP 采样流中的错误按统一资格规则识别，Responses 控制帧顺序保持兼容，真实错误可以正常呈现。

## 工具执行权限与资格

- MCP 工具调用资格改为按当前状态实时复核：服务器被禁用或能力上限收紧后，新的调用会被拒绝，不再沿用初始化时的旧资格；原有截止时间与无重放语义保持。
- 修复 ripgrep 通过 `--hostname-bin` 执行外部 helper 时绕过权限的问题：权限询问、自动放行与授权判定按实际执行的命令进行，`--glob --` 等绕过形式被拒绝。

## 规则与 LSP 会话归属

- 项目规则按物理 checkout 归属，linked worktree 不再误用其他 checkout 的规则。
- 每个会话的 LSP 只取本会话的插件快照：同目录不同插件集的并行会话不再互相污染 LSP 来源，且不触发全量 reload。
