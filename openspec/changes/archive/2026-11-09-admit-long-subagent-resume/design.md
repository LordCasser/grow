## Decision

`bootstrap_initial_context` 保留来源校验、Surface、展示和 artifact 冻结，删除恢复分支的 80% 粗估门槛。启动后，子 Agent 的普通 Turn 以完整请求投影判断压缩与窗口准入。保留的 System 头之后的历史已经可参与压缩，复用既有 range、预算和终态语义。

同一个窗口百分比仍可用于 fork 的 verbatim 与 normalized 路径选择。派生恢复继承 canonical source cut，并由新子 Agent 持久化其自身压缩与终态。

Seed 用户项没有本地 prompt 编号。选区规划在首个已编号边界之前用有历史模型响应的用户提示作为历史段起点，单独的运行时前缀不产生边界。回合索引、近期保留预算和完整响应组继续使用现有规则。
