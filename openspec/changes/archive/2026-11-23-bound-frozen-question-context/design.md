## Selection

先以完整冻结历史为输入做现有 portable 投影，沿用整份快照对重复 call ID、部分完成批次和模型技能元数据的判断。输出条目携带原始下标。保留全部系统消息和完整的包装后问题。用与 Attempt 相同的估值器从尾部选取连续的最近历史，单条消息或一次已完成的调用与其全部对应结果作为选择单位。这样同一超长用户轮次的近期证据仍能进入请求。附属于工具结果的模型技能元数据随批次进出；系统消息维持原序。

## Ownership and failure

两种问题入口继续持有原冻结来源的范围、修订和既有尝试上限。把所选历史的 Surface 坐标记录在 Attempt 中；冻结后新到达的历史不能进入重试。先选取再恢复图片，只处理选区内媒体，恢复后膨胀则在同一上限内重新判定准入，禁止偷偷换一组证据。输入准入失败写 Failed 与估值、上限；无回答采样、用量或成功收据。外部取消仍可经既有 guard 收尾。

## Adjacent behavior

ask_parent、ask_subagent、ask_session 共享回答方 actor；/btw 另有 overload 重试与仅展示输出。recap 和 memory flush 各自拥有不同的预算策略。保留现有 native continuation、公共投影、授权边界与重放兼容性。父子终态结果独立于问询，已完成工作的 child 直接返回结果。
