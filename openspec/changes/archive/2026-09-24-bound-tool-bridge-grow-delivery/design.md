# Design

The bridge receives the session's existing preview budget and attempt identity from actor spawn. TaskCompleted first admits its model-facing notification as before; the Grow projection clones only the task metadata and clears `TaskSnapshot.output`. When the producer requested a durable acknowledgement, the bridge reserves persistence credits and awaits that exact Grow append before forwarding the live projection. Otherwise a shared auxiliary dispatcher reserves both persisted and gateway copies before enqueue. TaskBackgrounded and ScheduledTaskCreated use that same two-copy path; ScheduledTaskFired and MonitorEvent are live-only and reserve one gateway copy. A failed reservation or append attributed to an active attempt closes that attempt's preview boundary. The small scheduled-task deletion tombstone retains its existing exact durable acknowledgement path.

The task output file remains the retrievable full-output source. The pager's completed-task row uses status, command, duration, and description; it does not read `TaskSnapshot.output` from this Grow projection. Monitor event text remains in its model-facing notification command and live UI event.
