# Design

`agent::discovery::agent_markdown_files` owns recursive source enumeration for native file-defined Agents. Its sorted lexical paths determine namespaced IDs; canonical paths are used only for traversal identity. Maintain a local HashSet of canonical directory ancestors, seed the current directory before descending, and remove it after returning. A repeated ancestor is skipped before read_dir. Canonicalization failure skips that directory under discovery's existing best-effort semantics; do not substitute a lexical path, which cannot prove absence of a physical cycle. A shared target reached through independent sibling aliases remains discoverable under each distinct lexical namespace. No public API, new dependency or cross-call cache is needed.

Tests use owned temporary roots and actual `discover_with_home`/existing source-discovery entry so parsed Agent IDs and scope are observed. Cover self-link, child link to parent/root, and independent alias to a valid external directory with nested definitions. The cycle produces only the finite real definitions; sibling aliases retain both namespaced IDs and sorted ordering. Existing project/user/bundled precedence and file loading remain unchanged. Unix symlink tests are platform-gated; no Windows field-equivalence claim. Parent reviews actual walker and runs relevant Agent discovery suite, then archives. The implementation is isolated while CLI compilation holds the main Cargo window.
