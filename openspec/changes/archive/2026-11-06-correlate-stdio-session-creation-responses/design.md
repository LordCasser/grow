# Design

`StdioReplayState` remains the sole bridge replay owner. Replace `pending_new: Option<CachedSession>` with a private request-ID-keyed collection; a `Vec<(serde_json::Value, CachedSession)>` with exact JSON value ID equality is sufficient at this boundary and avoids inventing a second ID type or assuming Value implements Hash. Only ordinary request IDs supported by the existing JSON-RPC wire should be admitted; a notification with no ID cannot be correlated and must not become pending creation. Distinguish numeric and string IDs. Reusing an in-flight ID is a protocol violation outside this fix; follow existing parsing conventions and do not introduce a duplicate-request policy framework.

Outgoing session/new records its own cwd/MCP snapshot under its ID. Incoming messages with a method are not responses. A response settles only the entry matching its exact ID; error or malformed success removes that entry without confirming a session. A successful matching creation with a valid sessionId inserts its own cached snapshot and updates last_session_id. An unmatched load or other response cannot take a creation's state. Outgoing load already owns its replay cache entry and primary selection; do not use an unrelated incoming response to overwrite them. A duplicate creation response cannot recreate an already settled pending entry. Unconfirmed creations are never replayed on reconnect.

Tests adapt existing one-pending cases, then drive actual forward plus incoming cache and reconnect replay: two creations in request order and reverse response order, numeric 1 versus string "1", a failed creation interleaved with an unrelated load response, and duplicate responses. Each confirmed ID must retain its own cwd/MCP payload and replay exactly once; errored/unconfirmed IDs never appear. Keep PB-01 actual-forward close controls green. No new transport, public schema, session lifecycle store or capacity policy is added. Parent reviews actual diff and runs the CLI suite; implementation stays isolated and exports only its delta relative to current main (including inherited PB-01/PB-07), never an entire main.rs replacement.
