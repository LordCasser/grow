## Confirmed architectural gap
`SessionActor::project_conversation_images_for_text_model_once` currently installs irreversible ImageShadows: after one route rejects an image, later routes also consume descriptions. This contradicts the newly requested first-image-attempt behavior for each provider/model tuple. Reuse durable original image evidence and validated description provenance, but make selection route-dependent rather than globally irreversible. Existing transport keys hash model/backend/endpoint, not canonical provider/model identity; inspect canonical route ownership before changing markers. No local OCR implementation was found in the image recovery chain. Keep the existing deadline, cancellation, concurrency and durable-write failure boundaries.
