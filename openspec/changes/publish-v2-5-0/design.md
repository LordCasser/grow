# Design

以已提交源码为唯一发布对象，tag 不移动。发布使用 LordCasser/grow 的 release.yml，保持四平台组全部启用、publish=true，所有门禁由既有 workflow 绑定到 tag 解析出的精确 commit。现有 draft 机制在资产、来源证明和校验和齐备前保持隐藏，不手动绕过失败门禁。

notes 明确 Timeline v27 新账本不迁移旧会话、恢复期间输入与 Ctrl+D、性能收益范围；GitHub 页面使用绝对链接。以本机既有质量回归为背景，实际发布仍依赖 tag 上的新 CI。下载十个平台资产逐一核对 checksum/结构，原生 macOS arm64 验证版本号、签名和 --help；其他平台运行状态按对应 CI 的实际能力记录，不把交叉编译称作原生运行。

失败先定位日志；只有明确瞬态故障才重试。需要源码修复时另建 change，不改已推送 tag；不能把部分成功发布成完整版本。仅保存最终结论与必要发布标识，原始构建/采集数据留在工作区外，下载与隔离 HOME 在验证后清理。
