## Why
All children inherit the shared Goal usage window, but only Goal-owned requests receive immutable Goal context. An ordinary Task child can observe a later active parent Goal and currently constructs a partial Goal turn owner, failing before work begins. Sharing budget admission is not delegation ownership.

## What Changes
Use the existing StartupHints.delegated_goal discriminator to restrict shared-window Goal identity inference for children. Ordinary Task children retain unowned turn identity; Goal-owned children retain strict complete-owner validation.
