# 1.1.5 — 2026-08-09

Grow 1.1.5 统一了 Behavior 与 Goal 控制面:Behavior 在 turn 采纳时捕获并随 Plan、Goal、Deep
Research 控制状态原子化持久化,Goal 从整文档变更改为带修订版本的 Markdown board 与类型化工具,
pager 行为可用性、Goal 投影与动效全部由结构化 Shell 状态驱动;同时为 `read_file` 带来 PDF
智能路由——文本层 PDF 默认走本地 Markdown 提取,扫描/混合 PDF 保留渲染到视觉模型路径。

## Behavior 与 Goal 控制面统一

- Behavior 在 turn 真正获得 foreground 时捕获进 `TurnContext`(`BehaviorId`),该 turn 的
  prompt、工具面与限制随后保持不变;切换 Behavior 不重标队列,也不改变已经运行的 turn。
- `tool_types::BehaviorId` 成为 Shell、Tools 与 Pager 的唯一身份,内部不再保留含义重叠的
  `SessionMode` / `PromptMode`(ACP `SessionModeId` 仅作为外部传输字段名;Pager `PromptMode`
  只表示输入框是否正在编辑排队消息)。
- `BehaviorCoordinator` 收敛为纯决策器:输入当前选择与 `BehaviorSwitchFacts`,输出
  `Applied | ConfirmationRequired | Rejected` 与 declarative effects;SessionActor 串行执行
  effect,在取消 owned work 之前先持久化目标 control snapshot。
- Behavior、Plan、Goal、Deep Research 控制状态原子化持久化;Plan、Goal、Deep Research
  继续由各自专用 runtime 持有状态机,不建立巨型通用状态机。

## Goal board 与工具面

- Goal 从整文档变更改为带修订版本的 Markdown board:planner 拥有任务结构,主 Agent 通过
  类型化 `update_goal_progress`(携带当前修订号与稳定 task id)更新状态、进度、证据与缺口,
  任务结构/摘要/范围/验收标准变化时调用 `request_goal_replan`,不再整体替换 board。
- Goal stage 引入精确 lease,subagent 能力按角色划定;共享 board 与运行时策略分离。
- turn 调度与 goal runtime 统一:完成顺序固定为结算 exact foreground owner → 持久化唯一
  `TurnCompleted` → 提升用户 FIFO → 仍 idle 时才运行 Goal idle hook,消除 synthetic
  prompt hot loop 与双调度器竞态。
- plan 修订时自动取消运行中的 verifier,避免基于过期计划继续验证。
- Goal 详情视图新增任务摘要与完整 board 查看器(两级渲染);Goal 生命周期以结构化
  session events 渲染进回滚区,不再由 pager 猜测阶段。
- 并发 turn 与 UI 状态加固:排队消息渲染、turn 状态行、快捷键与文档同步更新。

## read_file:PDF 智能路由

- 默认路由现在先分类页面:纯文本层 PDF 直接提取为本地 Markdown(`FileContent`),扫描/
  图片/混合 PDF 保持渲染到视觉模型路径(`PdfPageImages`);分类失败保守回退渲染,错误语义
  不变。
- 新增 `format="markdown"`:几何 span 拼接 + Markdown 转换(标题检测);表格密集 PDF 仍
  推荐图片路径(上游表格支持未完整实现)。
- `format="text"` 升级为按阅读顺序提取(`extract_page_text`),输出骨架不变,失败回退旧
  提取器。
- 提取警告(`ToUnicodeMissing` 等)作为诊断行输出,不再静默吞掉。
- `read_file` 改用 anydoc 文档管线统一 pptx/pdf 处理,移除全局 PDF 缓存。

## Pager 动效管线

- 动画/活动度与生命周期时钟分离:新增独立 activity 驱动,spinner、wave 等动效不再依赖
  watchdog 或 tick 分支。
- 完成事件驱动动效管线:pager-minimal commit/live/panel 与 pager-render 统一走事件
  推进,motion 语义与渲染时钟解耦。

## 其他

- `tools` 移除未使用的 `dirs` 依赖。
