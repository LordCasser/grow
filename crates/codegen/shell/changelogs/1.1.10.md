# 1.1.10 — 2026-08-15

## 会话搜索：开关与跨进程引导锁

- 新增 `[session_search] enabled`（默认开启）。关闭后本进程不再读写搜索索引，且进程内不可重新打开——避免用关闭期间缺失写入的半索引服务搜索；搜索请求返回带关闭来源的诊断错误（requirements.toml 固定 / `GROW_SESSION_SEARCH` 环境变量 / 配置文件三级优先）。
- 多进程并发时的索引引导改为跨进程单飞：引导租约写入索引自身 `meta` 表（原子 check-and-claim + owner token 围栏），一个进程重建时其余进程等待采用其完成标记；租约含过期、时钟回拨与陈旧 claimant 防护，重建中断由下一次搜索自愈。

## StopCancelled hook 事件

- 新增 `StopCancelled` 观察事件：turn 被用户取消（Esc / Ctrl+C）或中途 abort 时触发，在取消完全落地后 fire，hook 永远不会延迟取消本身。输入携带 `reason`（`hook_denied` / `permission_rejected` / `permission_cancelled` / `permission_timed_out` / `mid_turn_abort`，与 session 事件日志共享同一取消分类）和可选 `trigger`（如 `ctrl_c`、`esc`）。输出与退出码被忽略，matcher 不参与。

## follow-up 行为可配置：queue | steer

- 新增 `[ui] follow_up_behavior`（默认 `queue`，原行为）。设为 `steer` 时，运行中的 regular turn 收到 plain Enter 的后续输入会通过与 Ctrl+Enter 相同的 mid-turn interjection 入口自动并入该 turn；idle / compaction、synthetic 唤醒与 bash / 结构化输入不提升。
- turn 终止围栏语义：显式 steer 的残留照旧丢弃（turn identity）；自动提升的残留转回用户 FIFO 队首作为全新 turn，用户输入不被静默吞掉。未知配置值折叠回默认 `queue`。

## 用量与上下文 tabbed modal

- `/usage`、`/context`、`/info` 在 fullscreen / inline 模式下打开统一的 tabbed modal（Usage / Context / Session Info 三 tab，一次打开预取全部），行值可点击复制；过期的后台请求结果按 epoch 丢弃，重开不会串数据。minimal 模式保留原 scrollback 块行为。

## `grow du`：磁盘用量

- 新增 `grow du` 子命令：统计 Grow home 目录磁盘占用，按顶层条目分解；`--json` 输出机器可读格式（schema v1）。按物理块计费（`st_blocks × 512`）、不跟随子符号链接、跨卷不越界，且只读解析 grow home——不创建任何目录。安装落点解析复用权威 `default_grow_home`，与其它子命令路径一致。

## 内部质量

- 内置工具 → `ToolKind` 分类落为契约测试（allowlist 与 live registry 双向断言），主 agent All 模式保留全部内置工具的围栏有测试钉住；工具重分类成为显式评审动作。
- `CancellationCategory` 迁移为 hooks 层单一权威，session 事件日志、hook payload 与 workspace wire 层共享同一枚举。
