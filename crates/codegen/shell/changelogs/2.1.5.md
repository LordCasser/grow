# 2.1.5 — 2026-09-08

2.1.5 是本轮功能审查的阶段性版本，集中修复会话切换与恢复、模型请求、配置和扩展运行时问题，并完成已获批的两批非必要功能清理。

## 会话与模型请求

- 修复空闲会话切换 Agent/Model 后的 Behavior 准入判断，完善模型选择、reasoning effort 与持久记录的一致性校验。
- 加固会话恢复、rewind、草稿和异步结果的边界处理，避免旧任务结果覆盖当前会话状态。
- 改善跨模型及代理路由切换时的 native continuation 处理；遇到符合条件的缺失签名错误时，清理不兼容的 native 状态并进行有界重试。
- 加固认证辅助程序的缓存有效期、执行目录和错误输出边界，移除采样日志中的凭据片段；Trace 入口不再无故依赖模型配置成功加载。

## 历史搜索与图片

- `/history 关键词` 支持搜索历史对话内容并打开对应 session；`/history --prompts` 保留输入历史回填。过期搜索结果和错误不会覆盖新查询。
- 图片默认直接发送给模型。模型明确拒绝图片后，尝试配置的视觉辅助模型；失败或未配置时尝试本机 `tesseract` OCR，并显示处理提示。OCR 需要本机安装工具及所需语言数据。
- 原图与文字描述一起保留；图片能力按 session 内的 provider/model 记录。已标记模型使用描述，切换新模型先尝试原图。
- 两种图片降级都失败时，仅提示当前模型不支持多模态，并允许用户切换模型或自行 rewind；不自动 rewind、不丢弃原图、不将普通图片失败升级为 session 致命错误。

## 配置与扩展

- 修复 Hooks、MCP、技能发现、权限设置和客户端存储路径中的多项边界问题，补充对应回归和 OpenSpec 行为记录。
- 技能列表统一由 SkillManager 管理；移除未生效的技能 model/effort 元数据、旧 Skill 工具 IO、闲置 YAML 修复函数和无作用的 slash rewrite 参数。
- 移除 Shell 空 unstable feature、未接入的 ZDR access 字段、问答备用格式分支和旧权限持久化协议。有效问答内容、技能展开及现行权限设置流程保留。
- 完成第二批获批清理，移除 GBOOM、闲置诊断及输入状态、未接入的缓存开关、废弃图片入口和旧工作区辅助接口；每项删除均有独立回归与提交。
- 保留文件操作锁管理器和配置整份写入入口。OpenSpec SDD 流程及全仓静态审计资料已合入，审计快照与后续代码变更的差异另行记录。
- 修复 Linux 目录持久化的无效句柄错误，以及已结束 session 被较早存活 session 阻塞回收的问题。测试栈按未优化构建的实际需求调整。

每项获批删除均独立提交并执行对应回归。本版本不提供旧 Timeline schema 的迁移兼容层；本轮审查仍在继续。
