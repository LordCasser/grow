# 2.1.5 — 2026-09-08

2.1.5 是本轮功能审查的阶段性版本，集中修复会话切换与恢复、模型请求、配置和扩展运行时问题，并清理已确认未接入的接口。

## 会话与模型请求

- 修复空闲会话切换 Agent/Model 后的 Behavior 准入判断，完善模型选择、reasoning effort 与持久记录的一致性校验。
- 加固会话恢复、rewind、草稿和异步结果的边界处理，避免旧任务结果覆盖当前会话状态。
- 改善跨模型及代理路由切换时的 native continuation 处理；遇到符合条件的缺失签名错误时，清理不兼容的 native 状态并进行有界重试。
- 加固认证辅助程序的缓存有效期、执行目录和错误输出边界，移除采样日志中的凭据片段；Trace 入口不再无故依赖模型配置成功加载。

## 配置与扩展

- 修复 Hooks、MCP、技能发现、权限设置和客户端存储路径中的多项边界问题，补充对应回归和 OpenSpec 行为记录。
- 技能列表统一由 SkillManager 管理；移除未生效的技能 model/effort 元数据、旧 Skill 工具 IO、闲置 YAML 修复函数和无作用的 slash rewrite 参数。
- 移除 Shell 空 unstable feature、未接入的 ZDR access 字段、问答备用格式分支和旧权限持久化协议。有效问答内容、技能展开及现行权限设置流程保留。
- 保留文件操作锁管理器和配置整份写入入口；其余删除候选继续等待逐项审查。

每项获批删除均独立提交并执行对应回归。本版本不提供旧 Timeline schema 的迁移兼容层；本轮审查仍在继续。
