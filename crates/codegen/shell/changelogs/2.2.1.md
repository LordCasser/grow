# 2.2.1 — 2026-09-28

本版本强化工具权限判断的并发、撤销和持久化边界，并改善子 Agent 与模型路由信息的展示。

## 工具权限

- 权限提示和模型裁决按请求独立等待，新增有限准入与明确的过载结果，避免慢请求阻塞其他权限判断。
- Auto 裁决从入队开始受统一期限约束；Reset、权限模式切换和子 Agent 结束会等待旧请求撤销完成，迟到的允许结果不能授权或覆盖新状态。
- Reset 在内存中立即撤销旧授权，并在保存完成后确认；保存失败会向用户显示错误。权限请求明确标记主会话或子 Agent 来源，缺少完整身份时安全拒绝。

## 子 Agent 与模型信息

- Tasks 和打开的子 Agent 视图展示有效推理强度；可选在输入栏模型标签中显示 `provider/model` 路由。
- 修复并发状态更新和迟到生命周期通知下的子 Agent 状态、权限记录与 Goal 用量边界。
