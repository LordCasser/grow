# 2.1.7 — 2026-09-14

本版本集中改善会话恢复、模型请求可靠性、用量归属和父子 Agent 协作，并整理核心 crate 的依赖边界。

## 会话与模型请求

- 恢复并强化长 Timeline 的回放、续接和状态投影；恢复前校验已验证的 Timeline、用量结算和 Workflow 运行，避免损坏或过期事实进入活动会话。
- 加固 Chat Completions、Messages 和 Responses 的工具身份编码、原生 continuation、断流恢复及终止证据处理，保留可审计的原始事实并避免无效工具调用继续执行。
- 改善图片输入在模型请求、描述降级、上下文压缩和模型切换中的投影与预算处理，保留原图和可验证的描述来源。
- 更新版本策略、客户端身份和自动更新的组合边界，减少叶子 crate 对运行时实现的依赖。

## 用量与 Agent 协作

- 用量账本按主 Agent、子 Agent、Goal 和恢复分段稳定归属；状态栏、`/usage` 及恢复后的累计值保持一致，并保留不完整结算标记。
- 父 Agent 与直接子 Agent 支持可恢复的询问、立即介入和后续消息；接收、送达、权限和终态均写入可回放事实，避免迟到消息覆盖当前工作。
- 改善协作通知、工具行、权限提示和子 Agent 展示，保留原始输入与结果的配对关系，减少内部协议细节泄漏到用户界面。

## 验证与工程维护

- 增补会话生命周期、恢复、消息协议、用量、协作和客户端展示的回归测试与 OpenSpec 归档记录。
- 更新核心回归 CI、开发指南和架构说明；发布工作流继续构建并校验完整的平台资产集合。
