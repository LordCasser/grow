# 2.2.0 — 2026-09-24

本版本强化长会话与高负载下的恢复、资源边界和交互响应，并改进 Agent 上下文、协作通知及终端媒体处理。

## 会话恢复与采样

- 统一 response admission 与 replay projection 的持久化边界；恢复、fork、rewind 和 resident 重连沿用可核对的 response identity，durable ACK 丢失后重试仍保持幂等。
- 为采样预览、会话事件交接和 leader 候选暂存增加有界预算与背压；候选正文不再提前复制到持久化队列，超限或暂存失败会明确拒绝本次接纳并同步观察者。
- 保留 portable reasoning 阶段与冷恢复时的模型路由身份，避免 provider route 改变后悄悄延续旧会话。

## 协作、权限与工作流

- 改进 Agent 和子 Agent 的依赖驱动上下文，保留工具证据和阶段信息；会话协作通知采用有界投递，并在结束、重连和取消时保持来源与生命周期一致。
- 校验权限选择及 scope metadata，限制子 Agent 权限投影中的敏感细节，并确保关闭会话时撤销未完成的权限请求。
- 保留含糊的 Workflow spawn 结果供恢复核对，避免把未确认的启动状态误报为完成。

## 交互、媒体与本地资源

- 限制剪贴板图像读取、图像归一化、终端图像输出、overlay 转换及内联媒体加载的内存与处理时间；Kitty 图像粘贴增加终止边界探测。
- 将 Agent 目录切换、文件搜索、历史回放和本地草稿 I/O 移出交互热路径或限制其排队与保留量，改善恢复期间的输入响应。
- 为统一日志、调试输出和本地草稿隔离增加配额与保留边界；本地搜索替换在提交前重新确认文件身份，减少并发编辑造成的误写。
