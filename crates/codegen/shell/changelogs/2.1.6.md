# 2.1.6 — 2026-09-10

本版本集中改善模型断流恢复、Goal 用量统计、父子 Agent 通信和压缩后的任务续接。

## 模型请求与恢复

- Chat Completions、Responses 和 Messages 能区分缺少结束标记的断流、协议冲突和完整但无效的工具参数。在输出可撤回且预算允许时，断流和无效生成会进行有界恢复。
- 采样重试与会话修复共享调用次数和期限。每次真实调用都先结算用量，再决定是否继续；失败尝试的消费也计入适用的会话、Goal 和子任务预算。
- 修复失败预览在重试、历史回放及断线重连后残留的问题。工具仍在响应持久化确认后执行；Minimal 和不可撤回的客户端输出保留严格恢复限制。
- 修复无签名 thinking 回退后，下一请求只有工具结果、缺少对应调用的问题。压缩、恢复和切换模型后也保留完整工具往返，清除旧推理与签名，并保留图片被预算淘汰后的说明文字。

## Goal 与用量

- Goal 预算包含缓存命中的输入 token，详情显示缓存命中、未命中、输出及完整数字分隔。
- `/usage` 展示 provider/model 分类和加权缓存命中率；普通主会话状态栏显示累计用量，点击可打开 Usage。
- 修复 `get_goal`、`create_goal` 已完成但界面仍继续计时的问题，减少提示中的例行 Goal 查询。
- 修复子任务继承 Goal 身份和共享预算准入的边界；迟到用量结算保留已停止 Goal 的状态。

## 协作与会话

- 子 Agent 可以向直接父 Agent 提问，父 Agent 可以询问直接子 Agent；回答使用独立的只读上下文，不打断目标的前台工作。
- 修复 Windows 在并发读取时更新协调清单、加载运行中会话的文件共享冲突。
- 父 Agent 可向运行中的子 Agent 发送立即介入或下一步骤处理的消息。消息先持久化接收，再确认送达。
- 异步压缩摘要明确历史范围，并在已获准的下一步骤补充任务续接提示，避免旧摘要中的完成结论覆盖更新任务。
- 加快长 Timeline 的恢复，保留完整校验和实时写入原子性；Workflow 恢复等待上一执行的持久化终态确认。
- 修复大段粘贴跨输入批次被拆分，以及插话历史回放显示内部提示包装的问题。

用量状态栏与 `/usage` 统计当前进程启动或恢复以来的消费；Goal 保留其独立的持久化累计窗口。未取得完整用量时继续显示不完整标记。
