# Grow 2.6.2

本版本集中修复长会话退出、输入恢复和会话资源归属，并补齐插件安装、更新与 PTY 生命周期的错误反馈。

## 会话退出与恢复

- 减少长历史退出时重复复制和重放：整树挂起直接查询已验证的 runtime 与子任务事实，图片清理复用已提交引用，不再为清理重读整份 journal。保留五秒挂起期限和真实持久化、actor/writer 退役屏障。
- 编辑排队输入后，恢复会话保留原队列位置，并消费编辑后的不可变输入身份；转向消息恢复到原回合，重试沿用稳定身份。
- 项目规则按物理 checkout 归属，linked worktree 不再借用其他 checkout 的规则；会话的 LSP 与 Skills 目录使用各自已确认的插件快照。

## 问答与子 Agent 控制

- 新增建议式问答。允许该模式时，Agent 可在任务继续后接收补答，补答按普通输入接纳；关闭建议式后，实时和恢复会话都使用阻塞式确认。
- 子 Agent 模型调整如实展示已排队、已生效和失败状态；已排队不表示已生效，生效提示只出现一次。
- 直接修改 Skills 配置也会刷新 leader 与 in-process 会话的可调用目录和 slash 广告；custom roots 的监听跟随最新配置，登记失败保留原有效 owner。macOS discovery 使用 metadata polling，避免 FSEvents 注册阻塞。
- Skills 界面的请求和回包保留 session 与绑定 epoch，切换会话后旧结果不能覆盖当前目录或错误状态。

## 插件与工具

- ACP 插件更新按实际更新结果保存安装记录，分支更新、无变化、固定 revision 与本地目录结果使用同一应用路径。
- 普通插件安装在 registry 读取、解析或保存失败时返回明确错误。已发布但未完整登记的文件会保留并说明状态，不继续自动启用或伪报安装成功。
- SDK MCP reverse 调用绑定注册会话和连接；其他客户端成为 driver 或加载 resident 会话不会接管 SDK 调用，注册者断线也不自动转发到其他连接。冷恢复按新声明重绑，继承的 SDK transport 保留原 invoker。
- MCP 工具每次调用按当前服务器资格复核，服务器禁用或权限上限收紧后拒绝新调用。
- 修复 ripgrep `--hostname-bin` 外部 helper 的授权识别；权限判定按实际执行命令进行，并拒绝混淆参数边界的绕过形式。
- 流式采样的 error 信封按统一资格规则识别，保留合法 Responses 控制帧顺序。

## PTY 与崩溃证据

- PTY 的 stop、timeout、自然退出和 I/O 由同一直接 child owner 结算；EOF 不再被当作 child 已退出。CLI/HTTP/WS 消费同一终态，linger 保留最后状态，显式 stop 和 timeout 仍会关闭服务。
- 服务启动失败会清理本次 child；慢连接收束有界并明确报告失败。`--force` 仅替换名称登记，旧服务退出不会删除新登记或停止新进程。
- 开启 crash capture 时，各进程保留独立文件身份与 OS claim；恢复只消费成功 claim 的已退役 capture，同秒崩溃历史不会互相覆盖，报告持久化失败继续保留 raw 证据。
- 现有 crash 格式缺少 module/load provenance，恢复保留原始 IP 并明确无法自动符号化，避免把旧地址误归因到新进程的函数。

## 验证边界

本地候选验证记录见仓库 `openspec/changes/archive/2026-11-07-prepare-release-v2-6-2/verification.md`。Windows 相关改动包含交叉编译检查，未以此替代 Windows 原生执行。当前 crash 格式不新增 module/load mapping；macOS 通用文件监听的退出抖动保留在 backlog，不承诺所有 OS 调用都在固定时间内返回。
