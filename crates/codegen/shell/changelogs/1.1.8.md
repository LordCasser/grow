# 1.1.8 — 2026-08-13

Grow 1.1.8 修复子 Agent 并行工作时权限判断被滥用、隐藏 Ask 提示超时以及拒绝后整个 turn
被取消的问题，并将能力围栏与权限模式重新收敛为两条正交轴。版本同时补齐三个 API backend 的
结构化权限判断、权限审计 TUI、文本模型图片恢复和运行中模型目录热更新。

## 子 Agent 能力围栏与权限模式

- `capabilityMode` 定义 live child 当前可见的能力围栏，不再替代权限模式。围栏内普通 Read、Grep、
  Edit、Bash 和已授权 MCP server 调用直接沿正常流程执行，不调用主模型，也不生成权限审计噪声。
- Shell heuristic 仍可对不透明脚本、环境展开等二次风险重新请求裁决；`always-approve` 直接允许，
  `auto` 使用主 Agent 判断，`ask` 将提示显示在所属主任务。Managed deny/ask 与硬安全边界继续优先。
- `request_tool_access` 只用于显式突破当前围栏。原生能力按能力授权，MCP 按 server 授权；同一 live
  child session 内不重复批准同一 server，transport incarnation 变化仍会使旧授权失效。

## 主上下文 Auto 判断与失败语义

- 子 Agent Auto 默认通过 `[subagents].classifier_input = "context"` 使用主会话当前模型，并从已经
  压缩的上下文中只提取带 first-party 证据的真实用户任务与插话创建只读临时分支；assistant、tool
  result、summary 和 synthetic user-role 内容不具备授权能力。可设为 `"request_only"`，只发送待裁决
  动作以节省 token。两种
  分支的临时权限消息、原始模型响应与结构化裁决均不写入 ChatState、memory、compaction 或后续
  子 Agent fork。
- OpenAI Responses 使用 `text.format=json_schema`，Anthropic Messages 使用
  `output_config.format=json_schema`，DeepSeek、BigModel 等 Chat Completions 兼容后端使用
  `response_format=json_object`，并统一严格解析 `{decision, reason}`、拒绝额外字段。
- 空响应、非法结构、瞬态 provider 错误和单次判断超时最多重传一次；两次尝试共享总 deadline。
  最终 deny、timeout 或 unavailable 均 fail closed 为当前工具失败，不回落到隐藏的人工等待。
- 子 Agent 的 PolicyDeny、Reject 和 TimedOut 不再取消整个 turn：同批其他工具继续，模型获得下一次
  采样并可改用剩余能力；仅显式用户取消、父任务终止和 session teardown 保留 turn 级取消语义。
- nested subagent 的初始 capability 必须落在 immediate parent 的不可变 delegation ceiling 内；运行时
  fresh grant 不向后代传播，MCP 继承同时校验 server name 与 transport incarnation。

## 权限审计与交互

- Ask 权限提示统一承载在所属主任务的根交互层，后台 child 和打开的 child transcript 都能立即看到
  并回答，不再静默等待 60 秒后超时。
- 主 TUI 持久化每个子 Agent 权限结果，但不写模型上下文。同一主 Agent turn 完成前到达的权限消息
  合并为一个可折叠组，组内保持单行紧凑展示，组外恢复正常消息间距；双击某一行打开该条完整
  live 请求与完整 classifier reason，不做长度截断。落盘/replay 副本只保留带标签的脱敏安全摘要，
  避免命令、MCP 参数或 URL secret 进入 `updates.jsonl`。
- 权限行使用与 Subagents 面板一致的 Agent title，不再以 session ID 作为可见名称；详情仍保留
  完整 child session、来源、原因与判断耗时供诊断。

## 图片、模型目录与反馈

- 文本模型明确拒绝图片输入时，Grow 可使用辅助模型描述图片或原子移除图片后重新采样；图片负能力
  按 runtime identity 记录，切换 provider/model 后不会错误继承。
- 图片错误识别收紧到真实 input-type 拒绝，损坏图片、尺寸、格式和安全策略等 400 不再误触恢复。
- Pager session 共享 config watcher/reloader，`provider`、`models` 与默认 `model` 变化可在运行中刷新
  模型目录；Dashboard 明确提示选择对下一个 session 生效，重复选择当前模型显示 `Already using`。
