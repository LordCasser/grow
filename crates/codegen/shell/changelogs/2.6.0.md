# Grow 2.6.0

2026-11-04

本版本调整 Dashboard 会话操作，拆分子 Agent 观察工具，并修复退出恢复、图片上下文和记忆刷新链路。

## Dashboard 与会话操作

- 总览选择只更新只读预览，Enter 或双击打开普通会话详情；回复、权限和问题处理在详情中完成，Ctrl+\ 返回总览。
- 新会话输入与搜索各自保留草稿；输入聚焦时 Enter 只提交新会话，空稿不会打开背后选中行。默认使用稳定会话顺序，Ctrl+G 切换状态或目录分组；Ctrl+[ / Ctrl+] 按本地打开顺序切换会话。
- Ctrl+X 统一打开会话命令前缀：M/A/E/P/B 配置当前目标，C 关闭并保留历史，D 请求永久删除。重复前缀只停止工作，空闲会话保持打开；删除使用独立确认。
- 关闭等待 runtime 确认，永久删除核对运行状态与真实结果引用；独立 fork 可单独删除。失败的 fork 或历史加载保留可恢复的输入，加载期间仍可导航到其他会话。

## 子 Agent 工具

- 新增 `list_subagent(scope="active"|"all")` 发现当前及历史 child，`get_subagent_status(subagent_ids)` 查看状态与可信统计，`wait_subagent(subagent_ids, timeout_ms)` 等待并取得最终结果。
- 后台命令输出统一为 `get_command_output`。移除旧的 `get_task_output`、`get_command_or_subagent_output` 和 `get_terminal_command_output` 名称；自定义 Agent 的显式工具清单需同步更新。
- ACP `grow/tool` 元数据提升为版本 6，增加 `subagent_list`、`subagent_status`、`subagent_wait` 三类 kind；使用闭合类型的客户端需按新 schema 更新。
- 子 Agent 清单和详情不消费完成通知；缺失样本、查询超时或 runtime 不可达保留观察未知。挂起和收尾中的 child 仍可发现，等待被打断不会取消 child。
- 终端命令与子 Agent 取消入口分开：`kill_terminal_command` 只停止后台命令/monitor；`kill_command_or_subagent` 可取消 child，且不依赖 Terminal 资源。
- 冷恢复后可只读查询获准访问的原 child 结果；恢复在父 MCP 初始握手完成后重绑连接，沿用出生时的成员和能力边界。任务恢复保留继承 transcript，完成后释放可重建的内存投影。
- 工具相关的枚举、状态和等待提示随当前 Agent 工具集合渲染，缺少对应能力时不提示不存在的入口。

## 输入、退出与恢复

- 长 steering 输入保留完整正文。询问与 Agent 回复按持久身份交付，上下文补充与执行干预分别处理，回复不会被当成人工授权。
- 退出按 runtime 实际所有权挂起会话树，覆盖前台已空闲但后台 child 仍运行的情况；冷恢复保留项目规则，失败的恢复候选可在条件修正后重试。
- 恢复后的 Plan 审批绑定同一提交快照，避免把旧正文与新 revision/hash 拼接后批准。

## 运行时与命令收尾

- Native config/discovery watcher 注册、刷新和释放由 blocking owner 执行，避免阻塞 ACP/session command executor；取消等待不声称能中断已进入 OS 的 watch 调用。
- Unix 命令收尾在 reap leader 前完成所属进程组的终止责任，覆盖 leader 先退出而后代忽略 TERM 的场景；Windows 继续使用 Job Object 清理进程树。

## 图片、记忆与显示

- Recap、Memory Flush、Side Question 和协调询问复用已确认的图片描述与来源坐标，避免辅助请求绕过当前图片投影或重复描述已处理图片。
- Memory Flush 解析完整辅助模型路由，修复空闲手动刷新、禁用记忆时的准入和恢复后的自动 Recap 时钟。
- AI suggest、prompt suggest 和 Memory note rewrite 按配置 catalog ID 使用完整辅助模型路由；provider wire-model 名称本身不选择 endpoint 或 credentials。临时工作区跳过 daily log 写入时不推进成功 flush checkpoint。
- 共享 TUI 换行、截断与搜索列映射按字素边界处理，改善中文、组合符号和 emoji 的显示。
- 减少会话列表、图片预算选择、hunk patch、历史修复与检索重复计算；这些是局部算法优化，不代表所有真实负载的性能提升。

## 升级说明

工具观察接口、模型选择和取消边界已同步到内置 prompt 和用户指南。显式 child model 选择使用 Task tool 提供的 catalog ID；provider-facing wire-model 名称不作为路由标识。

新 child 的 Spawn 会记录出生 MCP 成员。旧版已挂起的 child 若缺少这一事实，升级后将拒绝执行型冷恢复；只读历史仍可查看。Grow 不使用当前配置补造旧授权，也不自动迁移这类 checkpoint。原有 Timeline 升级说明见 [2.5.0 说明](https://github.com/LordCasser/grow/blob/v2.5.0/crates/codegen/shell/changelogs/2.5.0.md)。
