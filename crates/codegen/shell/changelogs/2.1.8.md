# 2.1.8 — 2026-09-15

本版本修复上下文压缩选区和前台等待状态的反馈闭环。

## 会话压缩

- 修复最新 prompt 尾部不足保留预算时，压缩错误放弃更早可用响应组的问题；保留完整 prompt、reasoning 和工具往返。
- 修复手动压缩 actor 的结构化 ACP 错误被字符串化的问题，使已发布失败终态不会被 Pager 误报为结果未知。

## Pager 反馈

- 前台等待工具或子 Agent 时继续显示已接收的模型切换等实时控制反馈，终态清除后恢复原等待提示和任务操作。
- 增加压缩边界、RPC 错误透传和 parked 状态渲染回归测试，并归档对应 OpenSpec 验证记录。
