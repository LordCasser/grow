# 2.1.4 — 2026-09-05

2.1.4 收敛会话因果记录与发布质量：模型请求、失败响应和重试决定现在具备可校验的持久证据，长会话的 Timeline 前缀校验降低了峰值内存，控制语义和架构文档保持一致，并新增公共核心回归 CI。

## 因果记录与恢复

- 请求投影会记录来源 Timeline、图片逐出位置和 continuation epoch；实际发送的 provider body 在发送前获得持久化确认。
- 失败响应、部分流和 retry decision 保留原始证据；持久化确认失败或丢失时不会启动下一次请求。
- Sideband 调用复用同一不可变证据存储，恢复校验 artifact 的长度与内容 hash，但不会重新启用历史 native continuation state。
- 证据 body 按 64 KiB 内容块复用，导入导出保留无法按 UTF-8 解码的原始响应字节。

## 存储、控制与工程质量

- Timeline JSONL committed prefix 改为逐行限长读取、逐事件校验和增量 hash，避免首次打开时复制整份原始账本。
- 文档统一 Timeline schema v25，并明确 Sampling/Agent latest-wins desired slot、step boundary 和 Pager 重连语义。
- 新增无路径过滤的公共 PR 核心回归入口，覆盖核心 crate、Pager 和 CLI 构建；专项跨平台 workflow 保持独立。

本版本不提供旧 Timeline schema 的迁移兼容层。
