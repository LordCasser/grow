# Grow 2.3.1 — 2026-10-03

本版本改进只读回放界面，并修复恢复会话时历史通信记录的位置。

## 只读回放

- 回放页面沿用普通会话的状态栏、任务列表、子 Agent 导航和快捷键布局，同时保留只读边界。
- 播放控制随终端尺寸收敛显示，历史任务状态按播放位置更新。

## 会话恢复

- Timeline 中存在、展示缓存中缺失的通信记录会按可验证的对话锚点恢复到原有位置，不再集中追加到最新输入之后。
- 根会话、延迟加载的子会话和离线 transcript 使用一致的有序恢复与去重规则，保留原始身份和来源时间。
