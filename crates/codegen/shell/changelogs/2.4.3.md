# Grow 2.4.3 — 2026-10-20

补齐子 Agent 权限模式的设置入口，修正 Settings 回归覆盖，并将完整菜单集成测试纳入发布门禁。

## 设置

- Settings → Agent 新增独立的 Subagent permission mode，支持 Ask、Auto 和 Always approve，默认 Auto；保存后重启生效。
- 子 Agent 权限沿现有独立授权策略运行；设置保存使用原有顺序写入和失败回滚，只修改 `[subagents].permission_mode`，保留其他配置及环境引用。

## 回归与发布

- 补齐 Show model provider 的覆盖清单、Bool 类型、默认值及 typed setter 检查，并增加键盘和鼠标交互测试。
- 完整 Settings integration 测试纳入既有 Core 回归和正式发布的同提交门禁。
- 协调失败路径测试使用本地受控拒绝，移除对未监听 localhost 及时失败的依赖，保留原有期限和业务断言。
