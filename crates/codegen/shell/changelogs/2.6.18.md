# Grow 2.6.18

- 修复后台压缩失效后的交接，等旧任务结算后再启动下一次压缩。可选压缩找不到可用范围时，只要请求仍能放进模型窗口，会话就能继续。技能加载来源在会话恢复后仍可正确追踪。
- 子代理向父会话问询和用户发起 `/btw` 侧问时，会为问题预留模型窗口，并优先保留能容纳的近期历史和完整工具调用批次。
- `grow mcp doctor` 的文本与 JSON 输出分别报告连接、握手和工具发现结果。工具目录按总初始化预算读取，后续分页超时也会退出并给出失败阶段。
