# Grow 2.5.0 — 2026-10-22

重组会话历史存储与恢复链路，减少长会话恢复时的重复读取、解析和 TUI 扫描，并补齐恢复、持久化和展示回归。

**升级注意：** 本版使用新的会话账本格式（Timeline schema v27），不自动迁移旧会话。旧会话请继续使用原版本读取，升级前请备份 `GROW_HOME`。

## 会话历史与恢复

- 以单一 Timeline 账本保存领域事实、必要展示事实和顺序锚点，删除独立 updates 持久化与跨文件对账；已接纳响应正文只保存一份。
- 在同一恢复边界内复用已校验的根和子会话结果，减少重复读取、身份索引重建及投影构造。
- 保留完整历史校验、原顺序、持久 ACK、子会话归属和恢复后的继续输入；恢复期间普通输入保持关闭，Ctrl+D 可以退出。

2048 轮现代长文本会话、每轮约 32 KiB 回复正文的本机 release 配对基准：

各行分别是独立优化的前后对照，不是 2.4.3 与 2.5.0 的整版对比，降幅不能叠加。后端加载与屏幕可见是不同指标，末条历史可见也不等于可以输入。短会话和首屏没有一致提速，图片、磁盘与终端输出速度会影响实际收益。

测量环境为 macOS ARM64、温热文件缓存，每组 3 对 A/B 中位数；存储基准使用 Rust 1.93.1，TUI 两项使用 Rust 1.99.1、默认关闭诊断，均为普通 release 构建，而非正式发行包的 release-dist。

## TUI 与图片

- 按可见需要延后历史 Markdown 展示计算，减少布局重复维护、无效图片扫描和临时正文复制。
- 保留图片、Mermaid、raw/pretty 复制、历史选择与终端缩放后的布局和来源关系；快速恢复仍按实际吞吐向前滚动。
- 图片可在无文字草稿时提交，`/btw` 复用主会话已持久确认的图片描述，并保留失败后输入恢复。

## 周边修正与验证

- 整理内部消息布局、锁作用域和跨平台路径规范化，完成固定 Rust 1.93.1 下的 fmt、Clippy 严格检查与 release 编译验证。

- 修正技能、Runtime 收件消息和 thinking 历史的模型协议投影，保留原始工具结果和来源。
- 修正 MCP 工具目录分页与当前 Agent bridge 的目录同步；补齐 Settings 交互和偏好失败回滚测试。
- 增加现代长会话 release 基准及首历史发送、消费、绘制与 writer ACK 归因。收益依赖历史类型、帧节奏和输出速度，不承诺所有会话的首屏均加速。
