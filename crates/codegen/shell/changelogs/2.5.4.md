# Grow 2.5.4

2026-10-29

本版本修复上下文压缩、模型切换与恢复的状态衔接，并统一工具和 Thought 活动展示。

## 上下文与恢复

- rewind、模型路由替换后按当前实际回放重建上下文压力；完整 provider 回执即使低于本地估值也参与校准，连续压缩与再增长不会丢失保留内容的计数。
- 显式输出预留导致总窗口超限时先走有界预压缩；prune、图片重投影、后台提升和最终请求准入采用同一预算。压缩后仍放不下会结束本轮，保留已提交摘要及完成状态。
- 修复压缩取消、重复提升、持久化 ACK 丢失后恢复和异步通知的衔接，避免假零计数、重复提交及残留压缩提示。
- 冷恢复和 Goal 生命周期控制提交后立即同步请求作用域；Plan handoff 已由当前 Turn 消费时可幂等核对，其他 Turn 与已撤销 receipt 仍被拒绝。
- 不可验证的子会话完成观察不能再生成成功结果；后代展示恢复校验真实父子关系，并避免无事件 ID 的历史任务行重复出现。

## 终端与运行时

- 连续工具调用、子任务与交错 Thought 统一成可折叠活动，保持真实时序、失败信息和手动展开；live 与 replay 沿用相同语义。
- 关闭 sticky prompt 或使用 compact prompt 时，精确导航和居中不再保留多余 header 行。
- 配置与技能 watcher 的系统注册移到阻塞运行时，ACP 初始化可在注册等待期间继续；操作系统注册本身仍不能取消。
- `/btw` 接收端关闭后结束对应侧问；本地 OCR 与 PTY 测试 daemon 补齐进程树所有权和退出清理。
- 修复 Git/worktree 构建身份监听、Chrome duration 记录及若干测试的协议同步和构建模式边界。

## 存储边界

延续 Timeline v27，不改历史会话格式。升级说明与原存储边界见 [2.5.0 说明](https://github.com/LordCasser/grow/blob/v2.5.0/crates/codegen/shell/changelogs/2.5.0.md)。
