# Grow 2.4.1 — 2026-10-19

本版本修复会话退出与恢复、Windows 导出和技能加载，改善视觉辅助、Agent 通信与 Plan 的使用体验，并补强发布回归门禁。

## 会话退出与恢复

- 修复 Ctrl+D 退出请求未确认后无法再次重试、提示在部分页面或窄窗口不可见的问题。默认仍使用一秒内连续两次 Ctrl+D 确认退出；Ctrl+C 保持输入清理与取消当前回合的行为。
- 修复挂起期间辅助命令继续进入导致会话线程崩溃的问题。退出按同一操作身份等待结果，不把超时当作成功，也不强行丢弃仍在结算的工作。
- 减少树挂起、状态观察和父子交接中的重复历史复制与验证，并补充阶段耗时记录，改善长会话退出时的响应。
- provider 返回错误或无法解析的内容、自动恢复耗尽后，同一会话可以通过新的用户输入继续工作。子 Agent 按真实已结算用量保留剩余额度，不把一次失败直接当作预算耗尽。
- Goal 失败暂停后，普通“继续”可发起独立用户回合，但不会自动重启 Goal 或重置预算；恢复 Goal 仍使用显式 restart 并通过原有预算检查。

## Skill 按名称与渐进加载

- 技能目录复用启动扫描和刷新结果，只向模型提供名称与必要元数据；加载正文统一使用 `load_skill`，无需猜测文件安装路径。
- 支持按技能名称读取一个包内资源，按需逐步加载，不递归展开全部引用或执行脚本。
- 禁用、不可用或被拒绝的技能明确返回无法加载，不指导通过 Read、Shell、同名副本绕过。初始化声明的技能无法加载时明确报错。
- 保留用户选择与模型调用的统一授权、原子发布和恢复边界；不把普通文件阅读误标为技能加载成功。

## 视觉辅助与 Agent 通信

- 辅助识图请求只发送图片和固定英文提示词，不携带当前任务、Skill 或会话历史。图片描述保留原语言，TUI 固定操作文案使用英语。
- 识图、OCR 和转换结果在同一条普通操作行更新；修复重连后操作行重复、子 Agent 缺少图片恢复进度的问题。
- 内部图片投影占位句不再作为对话正文显示，也不再反复进入主模型与子 Agent 的派生历史。正常说明文字和 `Converted 1 image` 操作行保留。
- 会话内与跨会话 Agent 消息使用带身份的通信操作行，减少重复展示；“收到”只表示接收，不暗示对方已经执行。
- 重选当前 Agent、provider/model 和相同采样设置时，不再出现虚假的切换提示；真正变更仍显示控制结果。

## Plan、TODO 与失败处理

- 切换 Agent 时保留 TODO owner 与运行状态；切换 Behavior 时保留可恢复的 Plan 候选及提交计数。
- Plan 完成后保留只读 Plan / Result report 双 Tab，主视图显示简短总结。入口保留至下一次成功的手动 Behavior 选择，避免最终报告变成不可用的 artifact 占位。
- 压缩后重新发布持久规划状态，避免 TODO 在界面丢失。
- 工具执行链路失败会结束当前步骤并保留原错误，避免后续步骤继续运行或覆盖真正的失败原因。
- 修复 Bash 开启 `set -a` 后，大函数快照因临时变量自动导出而导致命令失败的问题；用户导出变量、函数和原选项继续跨命令保留。
- 修复持久 Shell 快照结束标记分块时的提前读取结束，并减少大快照标记检测的重复扫描。
- 系统指引默认优先将文件写入项目工作区及系统临时目录；项目外写入需要用户目标或任务必要性。这是行为指引，不是新增的文件系统沙箱。

## Windows 导出与发布验证

- 修复 Windows 上会话树 transcript / trajectory 导出的目录同步兼容问题，并补齐真实 HTTP 下载、父子会话归档和取消清理的回归。
- 发布门禁覆盖核心行为、真实进程恢复、三平台协调与导出、Windows 存储及 OpenSpec，均绑定最终发布提交；失败、跳过或取消会阻止发布。
- 精确测试选择会确认用例存在并确实执行，默认 CLI 构建独立于库测试检查，避免零测试通过或测试依赖掩盖生产编译错误。
- 修正配置监听 API 的注销边界，过滤失去项目所有者的迟到事件，同时保留共享祖先、全局及显式配置源的监听。

本版不包含独立 MCP 分支的 SDK / 策略身份改动，MCP 多轮交互继续暂缓。
