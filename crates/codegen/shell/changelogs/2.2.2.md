# 2.2.2 — 2026-09-28

本版本改进 prompt cache 用量统计与诊断，并修复模型设置中的 provider 展示选项。

## Prompt cache 与用量

- 保留 provider 报告的 cache read/write 用量及字段可用性，避免将未报告误计为零；状态栏和 `/usage` 按可用样本展示命中率与覆盖情况。
- 稳定跨请求的图片预算选择，并新增离线 prompt cache 诊断工具，帮助对比请求证据；不推断 provider 侧缓存命中结果。

## 设置与协作

- 修复 `Show model provider` 设置项，使其可在设置界面中启用。
- 保持权限请求隔离与撤销边界，并在任务视图中呈现子 Agent 的有效推理强度。
