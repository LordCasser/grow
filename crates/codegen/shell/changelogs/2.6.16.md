# Grow 2.6.16

- Ctrl+D 后恢复会话会保留已确认的 Behavior 和 Plan 阶段，不再依赖最近历史页是否含有切换记录。
- Plan 模式使用普通工具授权，提示词允许终端调查和有限实验，并要求计划获批前不得直接或间接实施。提示词的遵守仍取决于模型，不构成强制隔离。
- 主视图可连续加载旧历史，时间线可直接跳转到尚未加载的位置；Minimal 用 PgUp 打开历史屏、Esc 返回，浏览和退出不会重印已提交内容。
- 挂起前后的主模型、辅助调用和子任务消费按原稳定 Turn 归属恢复，session-only 消费仍只进入会话账本；完成结果保持冻结。待结算工作可见，未知费用和不完整标记不会被精确零替代。
- 浏览历史或调整终端宽度时，停在消息间隔中的视口会保持位置，不再跳回前一行正文。
- ACP 上下文 metadata 中的 `totalTokens` 字段更名为 `contextUsedTokens`；实际消费用量的 `totalTokens` 保持不变。

注：v2.6.15 为未公开候选，本版包含其全部已验收变更。
