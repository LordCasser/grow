# Grow 2.6.7

- 连按两次 `Ctrl+D` 确认退出后，Grow 持续等待会话挂起写入完成。挂起失败时可重试。
- 恢复后，已中断的命令出现在 Tasks 的完成历史中。显示的耗时包含按 `Ctrl+B` 转后台之前的执行时间。
- 冷恢复会重新检查 Goal 所需工具。暂停的 Goal 在 `/goal restart` 成功且工作就绪后自动接续。
- 排队消息在实际交付时才出现在对话中。取消前台命令时，尚未交付的输入按原队列继续处理。
- 会话列表默认发现在线会话。子 Agent 列表默认显示活跃及状态未知的任务，可用 `scope: "all"` 查看历史状态。
- `get_subagent_result` 可重复读取单一子 Agent 的已验证答案，并去重同一完成通知。`wait_subagent` 在任一目标达到终态后返回其 ID、状态和可用结果。
