# 2.3.0 — 2026-09-30

> [!WARNING]
> `grow export` 的命令行输出方式已改变：现在将会话树写入目录，不再向标准输出写入 Markdown，也不再支持 `--clipboard` / `-c`。已有的目标目录会被拒绝，避免覆盖先前导出。

## 会话记录

- `grow export <session-id> [output-dir]` 导出根会话及子 Agent 的独立记录，包含思考、工具调用、状态和中断边界；导出时固定只读快照，避免把仍在写入的记录误当作完整结果。
- `grow replay <session-id> [--speed <倍率>]` 在只读终端界面按时间回放历史，支持暂停、调整速度、浏览子 Agent、查看详情和选择文本。回放不启动模型或工具，也不写入原会话。

## 用量与终端界面

- 用户在模型输出途中补充输入时，状态栏继续展示已有可信样本的 prompt cache 命中率，并标明统计范围。Goal 状态栏、详情和只读回放也显示命中率；没有可计算样本时显示 `N/A`。
- Ask 卡片展示用户自由输入的实际答案；修正相邻工具组的选择边框、粘贴后的按键边界和文件搜索交互。
- Minimal 新会话欢迎卡在会话绑定后写入终端历史，避免首轮输出时消失。
- 当项目目录与用户目录指向同一 Workflow 路径时，只发现一次定义。

## 模型配置

- 文档和契约明确 `api_backend` 的覆盖顺序：模型级设置优先于 provider 默认值，同一 provider 可为不同模型选择不同 API 格式。
