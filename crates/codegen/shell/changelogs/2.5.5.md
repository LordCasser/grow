# Grow 2.5.5

2026-10-31

本版本修复 Plan 修订与确认、子 Agent 委派授权，以及压缩和挂起的交接问题。

## Plan 与任务

- 要求修改计划后，模型上下文保留本次完整反馈；已接纳决定通过精确回执自动关闭确认界面，迟到回执不会关闭新的审批。
- 窄屏操作栏按宽度换行，Minimal 的预览、行内批注、修订输入与提示保持一致；补充连续两轮修订、批准至完成的真实终端回归。
- 子任务启动前失败后，父 TODO 的后续修改不再等待无法运行的 child；恢复闭合遗留重规划。相同完成阻塞重复出现时停止本轮自动采样，保留具体原因供后续处理。

## 子 Agent 授权

- 委派以解析后的正式 ID 核对权限，区分未知类型、全局禁用和父 Agent 限制；插件别名遵守相同授权。
- 全局 toggle 热更新同步到已有普通主/子会话的派发与工具目录，CLI 定义在目录及重建时保留。
- 挂起恢复沿用 child 出生时的有效 RWX，再受当前父权限上限约束；缺失或损坏的出生事实阻止恢复。

## 压缩、挂起与更新

- 压缩完成后的存储准入失败保留具体错误，不再折叠为取消；已提交摘要继续保留。
- 挂起等待压缩持久化与结算排空后收回前台，避免等待已停驻的前台导致超时。
- 修复原生向量转换在分配失败时未初始化错误指针的问题，补充失败路径回归并消除对应 C 编译 warning。
- 取消标记统一为 `Turn cancelled`，不根据缺少来源的终态推断操作者。
- 未配置自动更新时默认开启，显式关闭继续生效；完整 TUI 在会话中显示版本和重启提示，Minimal 保留原有 notice。
- 改进模型路由切换后的上下文交接与 reasoning 兼容，并引导代理等待现有子任务。
