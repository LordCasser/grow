# 2.0.4 — 2026-08-30

2.0.4 收敛本地配置边界，修正新会话的项目选择时序，并让 Welcome、gate 与空会话使用可替换的字符 Logo。
本版本不改变既有 Session 数据格式，也不要求迁移 2.0.1 及之后创建的 session。

## 本地配置边界与覆盖

- 配置文件只保留全局 `$GROW_HOME/config.toml`，以及项目中从 repository root 到当前工作目录（cwd）逐层发现的
  `.grow/config.toml`。项目文件按距离由远到近应用，近层优先；其中会启动代码或服务的项目配置仍经过 folder trust，
  纯收紧项按各自 resolver 的语义生效。不再加载远程或系统级 `requirements.toml`、
  `managed_config.toml`，也不再同步签名策略或客户端内置公钥配置。
- “覆盖”不是所有子系统都采用同一个合并单位：MCP 同名 entry 整体替换，不合并字段；插件 `paths` 与 `disabled` 列表
  累积；权限 rules 累积，并按 `deny > ask > allow` 收敛；`[mcp].max_output_bytes` 取最近的受信项目值。
  具体配置位置与示例见 [用户指南配置说明](../../pager/docs/user-guide/05-configuration.md)。
- 上述删除仅针对配置层与其同步路径；插件 bundle 的 `GROW_DEPLOYMENT_KEY` 和 remote tool settings 不属于被删除项，
  仍按各自的插件或工具链路处理。

## 创建前的项目选择

- 从非项目目录创建新 session 时，项目选择器现在先立即显示，再异步补充最近项目；已在正常项目目录时直接创建，不经过 picker。
- Welcome 与 Dashboard 草稿会停放在唯一的 placeholder 上，连同附件、选择的 model 与 preferred session id 一起保留。
  选择、跳过或关闭 picker 都只产生一次最终 `CreateSession`；最近项目列表的迟到结果不会影响已经进行的选择或建会话，
  也不会再改写 cwd 或创建第二个 session。

## 可替换字符 Logo

- 可在 `$GROW_HOME/logo/big.txt` 和 `$GROW_HOME/logo/small.txt` 提供 UTF-8 字符画；缺失、空文件、不可读或无效内容会分别
  回退到内置 Logo。内置参考尺寸为 big `80 × 35`、small `50 × 22`。
- Welcome、项目 trust/startup gate 和空会话会根据可用终端宽高动态选择 big 或 small；自定义文件的实际显示尺寸会参与布局计算，
  不会按内置尺寸裁剪。完整场景尺寸、布局阈值和文件约束见 [Customizing the Grow Logo](../../pager/docs/user-guide/25-custom-logo.md)。

## Session 兼容性

Timeline schema v21、Sideband schema v6 和 Trajectory schema v3 在本版本均未变更。2.0.1 及之后的 session 不需要迁移。

## 发布校验

- GitHub Actions release 示例 tag 已更新为 `v2.0.4`。
- `scripts/validate-release.sh` 不再猜测旧版本 tag，必须显式传入 release tag，例如：
  `bash scripts/validate-release.sh v2.0.4`。
